HarvestT: Sistema de Agrotecnología Automatizado con IA
HarvestT es una plataforma integral de hardware y software diseñada para revolucionar la agronomía clásica mediante la automatización y el uso de Inteligencia Artificial. El proyecto se enfoca en la creación de invernaderos y germinadores inteligentes capaces de reproducir condiciones climáticas óptimas de manera autónoma.123
Características Principales
Monitoreo en Tiempo Real: Sensores integrados que miden luminosidad, humedad (ambiental y de suelo), temperatura y calidad del aire.41
Control Inteligente: Implementación de algoritmos de Machine Learning, agentes inteligentes expertos y lógica difusa para la toma de decisiones y análisis predictivo.125
Hardware Robusto: Basado en microcontroladores (como ATMEGA328/PIC) y computadoras de placa única (SBC) para gestionar actuadores de calefacción, iluminación LED de espectro completo y dispensadores de nutrientes.436
Ecosistema Digital: Aplicación móvil para notificaciones, alertas, planes de cultivo y visualización remota mediante cámaras internas ("watch and learn").46
Objetivos del Proyecto
Sustentabilidad Urbana: Facilitar el desarrollo de agricultura vertical y urbana en metrópolis como la CDMX.12
Optimización de Cultivos: Reducir el ciclo de crecimiento de las plantas controlando variables como el fotoperiodo.41
Impacto Social: Democratizar la agronomía permitiendo que personas sin conocimientos técnicos puedan cultivar sus propios alimentos de forma eficiente.1
Reconocimientos Internacionales
